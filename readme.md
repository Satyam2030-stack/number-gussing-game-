## Number Guessing Game (Python) in where we have to guess the numbers ##

A simple, interactive CLI-based Number Guessing Game built in Python. The program generates a secret number between 1 and 50, and gives the user 6 attempts to guess it correctly with dynamic hints provided along the way.

## Features OF NUMBER GUESSING GAME 
- **Randomized Gameplay:** Generates a new secret number every time the game starts.
- **Limited Attempts:** Users have a total of 6 attempts to guess the correct number.
- **Smart Feedback:** Gives real-time hints ("Too High" or "Too Low") after each attempt.
- **Robust Error Handling:** Catches non-integer inputs gracefully without terminating the application.
- **Interactive Pacing:** Includes realistic delays using `time.sleep()` for better visual experience.

## technologies used while making this game 
- **Language:** Python 3.x
- **Standard Libraries Used:** `random`, `sys`, `time`
